v2.7

  - Fixed Bug: fixed the main menu in IE10. In some situations, the domready JavaScript function was called twice causing problems.
  - Improvement: in the admin slider editor, set the maximum width and height to 150px for the thumbnails
  - Improvement: added new attributes for the [tabs] shortcode:
                  - active: specify which panel is currently open
                  - disabled: specify a comma-separated list of disabled tabs
                  - height_style: controls the height of the tabs widget and of each panel. Possible values: auto, fill, content
  - Improvement: added new attributes for the [toggles] shortcode:
                  - disabled: disables the accordion or one toggle if set to true
                  - height_style: controls the height of the accordion and of each panel. Possible values: auto, fill, content
  - Improvement: added a new attribute to the [post_carousel] shortcode
                  - display: allows displaying only the thumbnail or only the post meta (title, excerpt) or both (default case)
  - Added new filter: finesse_post_carousel_blog_thumbnail_settings - allows changing the settings for the post carousel thumbnail item in case of blog posts
  - Added new filter: finesse_post_carousel_portfolio_thumbnail_settings - allows changing the settings for the post carousel thumbnail item in case of portfolio items
  - Added new filter: finesse_portfolio_related_projects - allows changing the settings for the portfolio related projects
  - Added new filter: finesse_blog_related_posts - allows changing the settings for the blog related posts
  - Added new feature: the main menu background color and the text color can be modified via Theme Options
